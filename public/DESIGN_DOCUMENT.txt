1. EXECUTIVE SUMMARY & OBJECTIVE
--------------------------------------------------------------------------------
DealScout is a high-performance, hyper-local grocery circular aggregator, multimodal 
flyer digitization platform, and comparative unit-pricing intelligence engine. It empowers 
shoppers to discover active weekly grocery circular ads from physical supermarkets within 
a user-defined geographic radius (1, 5, 10, 20, 25, or 50 miles) based on live browser GPS 
coordinates or manual ZIP code / city search.

Unlike conventional grocery coupon apps that merely display static PDF flyers or present 
national deals from stores that do not exist in the shopper's area, DealScout:
1. Discovers verified local physical supermarket locations using OpenStreetMap Overpass POIs.
2. Ingests authentic weekly circular deals through a hybrid pipeline of live web scraping, 
   Google Search Grounding via Gemini 3.7 Flash, and user-uploaded multimodal PDF/image flyer OCR.
3. Normalizes all product pricing into universal unit economics ($/lb, $/oz, $/unit, $/egg, 
   $/gallon, $/count, $/dozen), dynamically parsing multi-buys ("2 for $7") and unpriced promos (BOGO).
4. Groups identical or substitutable commodities across competing local stores using a 
   rigorous 50+ key commodity taxonomy (e.g. distinguishing citrus types, pasta sauce from BBQ sauce, 
   cow milk from plant milk).
5. Employs Gemini 3.7 Flash AI to render decisive, side-by-side shopping value verdicts, 
   mathematical unit deltas, and purchase restriction caveats.
6. Continuously monitors the user's digital shopping list in real-time, alerting shoppers 
   whenever a cheaper alternative exists at a nearby competitor and enabling a 1-click swap.
7. Operates as an offline-first Progressive Web App (PWA) with background sync queueing, 
   service worker caching, and native push notification support.


2. CORE USER PROBLEMS & SOLUTION ARCHITECTURE
--------------------------------------------------------------------------------
Problem 1: Fragmented, PDF-Style Circular Flyers
Shoppers currently visit half a dozen disparate grocery websites or apps (Giant, Weis, Karns, 
ALDI, Wegmans, Target, Trader Joe's) to find weekly sales.
-> Solution: DealScout aggregates all active local flyers into a single, unified, searchable, 
   and filterable circular feed.

Problem 2: Deceptive Package Sizing & Shrinkflation
A 3-lb family pack of chicken breast at $8.97 looks cheaper than a 1.5-lb pack at $5.99, but 
the unit cost ($2.99/lb vs $3.99/lb) reveals the true value.
-> Solution: DealScout calculates normalizedUnitCost for every deal across all packaging 
   weights, enabling instant cross-store comparison.

Problem 3: Geographic Irrelevance & Phantom Stores
Coupons often promote chains unavailable in the shopper's region (e.g. Kroger in Central PA).
-> Solution: DealScout queries live OpenStreetMap supermarket POIs and verified regional 
   grocery directories, strictly enforcing user radius boundaries (1 to 50 miles).

Problem 4: Multi-Buy and Promo Confusion
Shoppers miss that "2 for $7" means $3.50 each or that BOGO promotions lack a single-item dollar price.
-> Solution: DealScout's pricing sanitizer detects multi-pack syntax, computes exact per-unit 
   prices, formats unpriced promos cleanly, and eliminates hallucinated MSRP strikethroughs.

Problem 5: Physical Paper Circulars Not Available Online
Small independent grocers or newly printed flyers may not be indexed immediately.
-> Solution: Multimodal Flyer Scanner allows users to upload flyer PDFs, photos, or take camera 
   snapshots; Gemini 3.7 Flash vision OCR extracts structured deals directly into the store catalog.

Problem 6: Spotty Connectivity in Grocery Store Aisles
Shoppers often lose mobile internet access deep inside concrete-and-metal grocery stores.
-> Solution: Full PWA support with service worker caching, safe local storage, and an offline 
   mutation queue that automatically syncs cart changes when network connectivity returns.

4. KEY SUBSYSTEMS & TECHNICAL SPECIFICATIONS
--------------------------------------------------------------------------------
4.1 Location & Geographic Radius Subsystem:
  - Dual Resolution: Live browser GPS (`navigator.geolocation`) and text search (ZIP, City/State).
  - Geocoding Engine: OpenStreetMap Nominatim with in-memory caching and instant presets for major 
    regions (e.g., 17050 Mechanicsburg, PA; 78701 Austin, TX; 32801 Orlando, FL).
  - Configurable Radius: Shoppers select 1, 5, 10, 20, 25, or 50 miles.
  - Spatial Math: Haversine spherical trigonometric formula calculates exact straight-line mileage.
  - Strict Boundary Filtering: Stores outside the chosen radius are excluded from deals and comparisons.

4.2 Store POI Discovery & Hybrid Circular Ingestion Pipeline:
  - Step 1 (Physical POI Discovery): Queries Overpass API (`shop=supermarket` & `shop=grocery`) 
    centered on target coordinates. Fallback regional matrices cover verified chains (Karns, Giant, 
    Weis, ALDI, Wegmans, Target, Trader Joe's, H-E-B, Publix, Kroger, Meijer).
  - Step 2 (Direct DOM Scraper): For specialized local chains like Karns Quality Foods, a Cheerio-based 
    scraper extracts authentic meat and produce weekly specials directly from source HTML.
  - Step 3 (Gemini 3.7 Flash with Search Grounding): Queries current weekly flyer circulars using 
    Google Search Grounding tools for live prices, promotional validity dates, and store flyers.
  - Step 4 (Deterministic Fallback Cache): If external network APIs or AI quota limits encounter 
    cooldowns, the system seamlessly serves curated high-fidelity snapshot circulars.
  - Step 5 (In-Memory Cache): 10-minute TTL in-memory map keyed by lat/lng/radius prevents duplicate 
    external requests during frequent client re-renders.

4.3 Multimodal Circular Flyer OCR Subsystem:
  - Multi-format ingestion: Supports PDF circulars, JPEG, PNG, and WebP image uploads or camera captures.
  - Image Preprocessing: Sharp library converts PDF pages or images, downsamples high-resolution flyers 
    to fit token constraints, and normalizes orientation.
  - Multimodal Vision Extraction: Gemini 3.7 Flash analyzes flyer imagery with structured JSON schemas, 
    extracting product title, subtitle, category, price, unit type, and promo badges.
  - Payload Handling: Express configured with 25MB body limit to accommodate multi-page circular flyers.

4.4 Pricing Normalization & Deal Sanitizer:
  - Multi-Buy Syntax Engine: Parses patterns like "2 for $7", "3 for $10", "4/$5" into exact per-unit 
    costs ($3.50/ea) while retaining the bundle description.
  - Unpriced Promotion Handling: Identifies BOGO ("Buy 1 Get 1 Free"), "50% Off", and percentage deals 
    without assigning misleading $0.00 prices or hallucinated MSRP strikethroughs.
  - Title & Brand Normalization: Removes crawler artifacts (e.g. leading "Branded" prefixes) and extracts 
    brand keys, flavor variants, and core base nouns.
  - Universal Unit Cost: Converts disparate package measurements into standardized units:
    * $/lb (meat, poultry, bulk produce)
    * $/oz (berries, coffee, sauces, snacks)
    * $/dozen or $/egg (eggs)
    * $/gallon (milk, cider, juices)
    * $/unit or $/count (avocados, bakery items, canned goods)

4.5 Strict Commodity Taxonomy & Matching Engine:
  - 50+ Normalized Commodity Keys: Prevents false-positive comparisons across incompatible sub-categories:
    * Citrus separation: `produce_oranges`, `produce_lemons`, `produce_limes`, `produce_grapefruits`.
    * Sauce separation: `pantry_sauce_pasta` vs `pantry_sauce_bbq`.
    * Dairy separation: `dairy_milk_cow` vs `dairy_milk_plant`.
    * Meat cuts: `meat_chicken_breast`, `meat_chicken_wings`, `meat_beef_steak`, `meat_beef_ground`.
  - Grouping Logic (`dealMatcher.ts` & `grouping.ts`):
    * Assembles competing deals in the same genericProductGroup.
    * Sorts items by `normalizedUnitCost` ascending so index 0 represents the mathematical best deal.
    * Calculates maximum unit price savings percentage and dollar differential across stores.

4.6 AI Comparative Shopping Verdict Subsystem:
  - Server endpoint `/api/compare/deals` invokes Gemini 3.7 Flash with structured JSON schemas.
  - Generates:
    * `bestDealId`: ID of the mathematically or qualitatively superior deal.
    * `verdict`: Decisive 1-2 sentence recommendation for shoppers.
    * `keyDifference`: Specific unit price delta, size advantage, or quality tier difference.
    * `unitPriceAdvantage`: Formatted comparative advantage (e.g., "$0.49/ea vs $0.77/ea - 36% cheaper").
    * `caveats`: Purchase conditions (digital coupon clipping, minimum quantity, loyalty card required).

4.7 Smart Shopping List & Cross-Store Savings Alerts:
  - State Storage: Browser `localStorage` via safe wrapper `safeStorage.ts` with quota resilience.
  - Real-Time Price Monitoring:
    * Evaluates every list item against all active store deals within radius.
    * If a competing store offers a lower unit price on the same commodity, generates an alert card:
      "Cheaper alternative found at [Competitor] - Save $X.XX ($Y.YY/unit vs $Z.ZZ/unit)".
    * 1-Click Deal Swap: Replaces the existing item with the cheaper alternative instantly.
  - Multi-store checklist with categorized items, quantity adjustments, and total savings tally.

4.8 Progressive Web App (PWA) & Offline Capabilities:
  - Service Worker (`sw.js`):
    * Cache-First strategy for static scripts, styles, icons, and design documents.
    * Network-First strategy with fallback cache for API circulars and location routes.
  - Background Sync Queue (`syncQueue.ts` / `useSyncQueue.ts`):
    * Captures cart mutations (add, toggle, remove, swap) when offline.
    * Flushes mutations to `/api/cart/sync` when online connectivity is restored.
  - Install Banner (`InstallBanner.tsx`) & PWA Hook (`usePWAInstall.ts`):
    * Captures `beforeinstallprompt` and renders a clean, non-intrusive in-app install prompt.
  - Push Notification Testing Suite (`DevTools.tsx`):
    * Simulates native system notifications with delay scheduling for background verification.

6. SECURITY, RELIABILITY & DEPLOYMENT ARCHITECTURE
--------------------------------------------------------------------------------
- Container Execution: Node.js 20+ runtime serving Express on port 3000 (0.0.0.0).
- API Key Protection: GEMINI_API_KEY is restricted strictly to backend code (`server.ts`, `geminiService.ts`). 
  Never exposed to the browser client or client bundles.
- Request Safety & CORS: Configured CORS middleware supporting cross-origin access and OPTIONS preflight.
- Resilient Fallback Cascades:
  * Overpass API failure -> Falls back to regional store directory matrices.
  * Live Scraper failure -> Falls back to Gemini Search Grounding.
  * Gemini AI quota limits -> Falls back to curated weekly circular snapshots.
  * Offline network state -> Serves cached circulars and queues local cart mutations.
- Documentation Endpoints: Built-in `/DESIGN_DOCUMENT.txt` and `/CODE_STRUCTURE.txt` plain-text streaming 
  routes ensure seamless in-app viewing and 1-click file downloads.
