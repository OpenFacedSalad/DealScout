2. DETAILED FILE-BY-FILE SPECIFICATION
--------------------------------------------------------------------------------

2.1 BACKEND SERVER LAYER

[server.ts]
- Purpose: HTTP server listening on port 3000 (0.0.0.0) serving both API routes and Vite/static frontend.
- Key Endpoints:
  * GET  /api/health
    Returns server status and timestamp.
  * POST /api/location/resolve
    Accepts { lat, lng, query }. Resolves coords or ZIP/city into { latitude, longitude, city, state, zipCode, formattedAddress }.
  * POST /api/location/geocode
    Accepts { lat, lng }. Reverse geocodes coords into { city, state, zipCode }.
  * POST /api/circulars/nearby
    Accepts { lat, lng, city, state, zipCode, radiusMiles }. Queries physical grocery stores within radius and generates/returns authentic weekly circular flyer deals for each store.
  * POST /api/compare/deals
    Accepts { productGroupName, deals }. Invokes Gemini 3.7 Flash AI to analyze competing deals and return bestDealId, verdict, keyDifference, unitPriceAdvantage, caveats.
  * GET  /DESIGN_DOCUMENT.txt & /CODE_STRUCTURE.txt
    Direct raw text file streaming for developers and AI assistants.

[server/storeFinder.ts]
- Purpose: Spatial analysis, geocoding, and physical supermarket location detection.
- Core Functions:
  * calculateDistanceInMiles(lat1, lon1, lat2, lon2):
    Implements Haversine spherical trigonometric formula to return precise miles.
  * geocodeQuery(query: string):
    Queries Nominatim OpenStreetMap API with instant cached resolution for popular ZIP codes (e.g. 17050 Mechanicsburg, PA).
  * reverseGeocodeCoords(lat: number, lng: number):
    Translates device GPS coordinates into clean City, State, and ZIP.
  * findPhysicalGroceryStoresOSM(lat: number, lng: number, radiusMiles: number):
    Queries OpenStreetMap Overpass API for real POIs tagged `shop=supermarket` or `shop=grocery` within radius meters.
    Includes built-in verified POIs for the 17050 / Mechanicsburg / Cumberland County, PA market (Karns Quality Foods, Giant Food Stores, Weis Markets, ALDI, Wegmans, Target Grocery, Trader Joe's).
  * getRegionalDefaultStores(city, state, lat, lng, radiusMiles):
    Provides authentic regional chains for PA, TX, FL, and national regions if OSM is unreachable.

[server/geminiService.ts]
- Purpose: AI orchestration with `@google/genai` (Google Gen AI SDK) using Gemini 3.7 Flash.
- Core Functions:
  * getAiClient():
    Initializes lazy singleton GoogleGenAI client with process.env.GEMINI_API_KEY.
  * getCircularsForLocation(lat, lng, city, state, zipCode, radiusMiles):
    Orchestrates physical store discovery, then requests Gemini 3.7 Flash to construct weekly flyer deals matching store identity (e.g. Karns butcher specials, Giant Choice Rewards, ALDI Super 6).
    Employs structured JSON schema enforcement (`responseSchema`). Includes robust deterministic fallback templates if AI is rate-limited.
  * compareDealsWithAI(productGroupName, deals):
    Analyzes competing store deals for a specific product group. Produces a structured JSON verdict explaining which deal is mathematically and qualitatively superior, along with caveats.


2.2 TYPES & UTILITIES

[src/types.ts]
- Core TypeScript interfaces:
  * DealCategory: 'produce' | 'meat_seafood' | 'dairy_eggs' | 'bakery_deli' | 'pantry_snacks' | 'frozen' | 'beverages' | 'household'
  * DealType: 'sale' | 'bogo' | 'digital_coupon' | 'multi_buy' | 'clearance'
  * Store: Represents a physical supermarket with address, distance, operating hours, logo styling.
  * DealItem: Represents an individual flyer deal with prices, normalized unit economics, brand, tags, qualityTier.
  * ComparisonGroup: Collection of competing deals in the same genericProductGroup with lowestPrice and AI analysis.
  * ShoppingListItem: Item saved in cart with quantity, checked state, custom title, and optional betterAlternative alert.
  * UserLocation: Geolocation coordinates, city, state, zip, formatted address, isGps flag, radiusMiles.

[src/utils/dealMatcher.ts]
- Core Functions:
  * groupSimilarDeals(deals: DealItem[]): ComparisonGroup[]:
    Groups all deals across multiple stores by `deal.genericProductGroup` (e.g. "ground_beef_80_20", "whole_milk").
    Sorts deals within each group by `normalizedUnitCost` ascending so index 0 is always the best price per unit.
    Sorts comparison groups by number of competing deals descending.
  * findBetterAlternative(item: ShoppingListItem, allDeals: DealItem[]):
    Scans all deals in active stores within radius. If an alternative deal exists in the same genericProductGroup from a different store with a lower `normalizedUnitCost`, calculates savings and returns a recommendation object.

3. END-TO-END DATA FLOW
--------------------------------------------------------------------------------
1. App Startup:
   App.tsx checks `localStorage`. If no saved location, prompts `navigator.geolocation`.
   Coordinates are sent to `/api/location/resolve` -> resolved to city/state/zip.

2. Circulars Fetching:
   `fetchCircularsForLocation(location, radiusMiles)` issues POST to `/api/circulars/nearby`.
   Backend executes OSM Overpass POI query filtered by `radiusMiles`.
   Backend invokes Gemini 3.7 Flash to retrieve authentic weekly circular deals for each store.

3. Price Comparison Engine:
   Frontend `groupSimilarDeals()` aggregates all returned deals by `genericProductGroup`.
   Finds lowest `normalizedUnitCost` store for each commodity.
   When the user opens a comparison, `/api/compare/deals` triggers Gemini AI to generate a detailed shopper verdict.

4. Shopping List & Cross-Store Swap:
   When deals are added to the shopping list, `findBetterAlternative()` cross-references all active deals.
   If a competitor within radius offers a cheaper unit price, an alert badge appears with a 1-click swap handler.
