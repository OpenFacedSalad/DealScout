2. DETAILED FILE-BY-FILE TECHNICAL SPECIFICATION
--------------------------------------------------------------------------------

2.1 BACKEND GATEWAY & API LAYER

[server.ts]
- Role: Primary HTTP server (Express 4) on port 3000 (0.0.0.0).
- Key Middlewares:
  * 25MB body parser (`express.json({ limit: '25mb' })`, `express.urlencoded`) for multi-page flyers.
  * Cross-Origin Resource Sharing (CORS) with OPTIONS preflight handling.
- Key Endpoints:
  * GET  /api/health: Returns API gateway status, service name, version (2.2.0), and environment.
  * POST /api/location/resolve: Geocodes search queries (Nominatim) or reverse-geocodes lat/lng.
  * POST /api/circulars/nearby: Fetches physical stores within radius and returns circular deals via hybrid pipeline.
  * POST /api/circulars/parse-flyer: Accepts base64 PDF or image, uses Sharp & Gemini 3.7 Flash OCR to extract structured deals.
  * POST /api/compare/deals: Invokes Gemini 3.7 Flash to generate AI comparison verdict, key difference, and caveats.
  * POST /api/cart/sync: Receives and acknowledges replayed offline cart mutations.
  * GET  /DESIGN_DOCUMENT.txt & /CODE_STRUCTURE.txt: Streams plain-text documentation files.
- Environment & Build Mode:
  * In development: Mounts Vite dev middleware directly on Express (`vite.middlewares`).
  * In production: Serves static compiled frontend assets from `dist/` with SPA catch-all routing.

[api/_lib/geminiService.ts]
- Role: AI orchestration engine leveraging the official `@google/genai` TypeScript SDK.
- Key Functions:
  * getAiClient(): Returns lazy singleton `GoogleGenAI` client configured with `process.env.GEMINI_API_KEY`.
  * getCircularsForLocation(lat, lng, city, state, zipCode, radiusMiles, executionMode):
    Orchestrates physical store discovery via OSM Overpass, performs live scraping / Search Grounding,
    and returns structured `Store` and `DealItem` lists with strict JSON schema compliance.
  * parseFlyerWithAI(fileBase64, mimeType, storeMeta):
    Preprocesses flyer images with Sharp, sends base64 payload to Gemini 3.7 Flash multimodal vision,
    and returns normalized `DealItem[]`.
  * compareDealsWithAI(productGroupName, deals):
    Produces structured `AIComparisonResult` with mathematical unit deltas and purchase caveats.
  * STRICT_COMMODITY_KEYS & NOUN_TO_COMMODITY_MAP:
    Enforces 50+ strict commodity taxonomy keys to prevent false comparisons across unrelated sub-types.

[api/_lib/storeFinder.ts]
- Role: Spatial geolocation and supermarket POI query engine.
- Key Functions:
  * calculateDistanceInMiles(lat1, lon1, lat2, lon2): Haversine distance formula implementation.
  * geocodeQuery(query): Nominatim forward geocoding with instant caching for common ZIP codes.
  * reverseGeocodeCoords(lat, lng): Translates coordinates into City, State, and ZIP.
  * findPhysicalGroceryStoresOSM(lat, lng, radiusMiles): Queries Overpass API for real supermarkets.
  * getRegionalDefaultStores(city, state, lat, lng, radiusMiles): Authentic regional fallbacks (PA, TX, FL, CA, Midwest).

[api/_lib/liveCircularScraper.ts]
- Role: Live circular retrieval engine with Google Search Grounding and fallback chains.

[api/_lib/karnsScraper.ts & api/_lib/karnsSnapshotData.ts]
- Role: Direct DOM HTML parser (Cheerio) targeting Karns Quality Foods weekly meat and produce ads,
  paired with verified offline snapshot data.

[api/_lib/dealPricing.ts]
- Role: Server-side pricing sanitizer matching multi-buy syntax and unpriced promotions.


2.2 FRONTEND STATE, HOOKS & UTILITIES

[src/types.ts]
- TypeScript domain models:
  * `CategoryType` / `DealCategory`: produce, meat_seafood, dairy_eggs, bakery_deli, pantry_snacks, frozen, beverages, household.
  * `DealType`: sale, bogo, digital_coupon, multi_buy, clearance.
  * `NormalizedUnitType`: lb, oz, dozen, pkg, each, unit, gallon, count.
  * `QualityTier`: budget, standard, premium, organic.
  * `Store`: Physical store POI with address, distance, flyer info, and branding.
  * `DealItem`: Comprehensive deal record with prices, unit economics, bundle metadata, and tags.
  * `UserLocation`: Geographic coordinates, address components, GPS flag, radius.
  * `ComparisonGroup`: Grouped competitor deals for a commodity with AI analysis.
  * `AIComparisonResult`: Gemini AI verdict, key difference, unit price advantage, caveats.
  * `BetterAlternative`: Competitor deal recommendation with savings calculations.
  * `ShoppingListItem`: Cart item with quantity, checked state, custom pricing, and deal reference.

[src/utils/dealPricing.ts]
- Function `sanitizeDealItem(deal: any): DealItem`:
  * Parses multi-buy strings ("2 for $7", "3 for $10", "4/$5") into per-unit prices ($3.50 ea).
  * Detects unpriced promotions (BOGO, % Off) and formats display badges without fake MSRPs.
  * Strips crawler artifacts (e.g. "Branded" title prefixes).
  * Calculates `normalizedUnitCost` based on weight/volume units ($/lb, $/oz, $/gallon, $/dozen).

[src/utils/dealMatcher.ts & src/utils/grouping.ts]
- Function `groupSimilarDeals(deals: DealItem[]): ComparisonGroup[]`:
  * Groups deals by `genericProductGroup`.
  * Sorts competing deals by `normalizedUnitCost` ascending (best deal at index 0).
- Function `findBetterAlternative(item: ShoppingListItem, allDeals: DealItem[]): BetterAlternative | null`:
  * Evaluates list items against active deals from competitor stores within radius.
  * Generates savings per unit and total potential savings if a cheaper alternative exists.

[src/utils/safeStorage.ts]
- Robust LocalStorage helper that traps `QuotaExceededError` and provides in-memory fallback storage.

[src/utils/syncQueue.ts & src/hooks/useSyncQueue.ts]
- Manages an offline mutation queue for cart operations (add, remove, toggle, swap).
- Flushes pending mutations to `/api/cart/sync` when network status transitions to online.

[src/hooks/usePWA.ts & src/hooks/usePWAInstall.ts]
- Registers the service worker (`sw.js`), handles cache update prompts, and provides `triggerInstallPrompt`.

[src/hooks/useNetworkStatus.ts]
- Tracks browser `navigator.onLine` status and triggers online/offline event listeners.

[src/hooks/useAutocomplete.ts]
- Provides debounced search suggestions for grocery items and supermarket chains.

3. END-TO-END DATA FLOW
--------------------------------------------------------------------------------
1. Location Resolution:
   - On load, `App.tsx` reads `safeStorage`. If empty, queries `navigator.geolocation`.
   - Sends coordinates to `/api/location/resolve` -> Nominatim returns City, State, ZIP.

2. Circular Ad Fetching & Ingestion:
   - Client sends POST to `/api/circulars/nearby` with lat, lng, radiusMiles, and location metadata.
   - Backend queries OSM Overpass for physical supermarkets.
   - Backend triggers hybrid ingestion (Karns scraper, Search Grounding, Gemini 3.7 Flash).
   - Ingested deals pass through `sanitizeDealItem` to normalize unit pricing and multi-buys.

3. Commodity Grouping & Comparison:
   - Frontend runs `groupSimilarDeals()`, indexing deals into strict commodity groups.
   - Computes lowest `normalizedUnitCost` store for each commodity.
   - Opening a comparison calls `/api/compare/deals` for Gemini 3.7 Flash shopper verdicts.

4. Shopping List Monitoring & 1-Click Swap:
   - Adding items to the shopping list triggers `findBetterAlternative()`.
   - If a competitor offers a cheaper unit price on the same commodity, an alert appears.
   - Clicking "Swap Deal" replaces the cart item with the competitor deal and recalculates savings.

5. Offline PWA & Sync:
   - When offline, cart changes are stored locally and queued via `syncQueue.ts`.
   - When connectivity is restored, `useSyncQueue` replays mutations to `/api/cart/sync`.
